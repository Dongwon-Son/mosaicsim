# PaletteSim

Fast Multi-Engine Neural Simulation

[Project page](https://dongwon-son.github.io/palettesim/)

GitHub Pages serves this static site from the root of the main branch. The project URL follows the PaletteSim repository name.

The title, header, and favicon use the approved PaletteSim icon. Its web derivative trims transparent margins and resizes the original; the original is preserved in `assets/palettesim-icon-original.png`.

The overview is the current paper’s Figure 1, with the original simulation renders and video frames. The WebP preview links to the exact figure PDF. The paper button opens the full author-identified preprint.

The hero uses the existing 7.36-second silent simulation loop. Reduced motion, data saving, offscreen/hidden-tab pausing, and the background pause button are supported. Only one foreground film plays at a time.

Benchmark values and footage timings are preserved. Internal media filenames and historical benchmark keys remain stable for existing links.
