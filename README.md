# MosaicSim

Multi-Engine Neural Simulation for Real-World Adaptation

[Project page](https://dongwon-son.github.io/mosaicsim/)

GitHub Pages serves this static site from the root of the main branch.


The hero uses a 7.36-second silent dense-simulation loop, derived from the accepted 4K render. The browser selects VP9 WebM or an H.264 MP4 fallback; it downloads one format. Both are 1920×1080 at the original 25 fps, with a short wrap crossfade. A JPEG remains visible when motion is reduced, data saving is enabled, or autoplay is unavailable. The background autoplays and loops by default, pausing offscreen or in a hidden tab. The small pause button controls the background independently of the two films.
The header, hero title, and favicon use the paper's four-tile symbol, with the exact tile spacing and orange, blue, green, and purple colors from writing/main.tex.

Figure 1 from the current paper appears between the showcase film and Policy transfer. A lazy-loaded 3200-pixel WebP keeps labels sharp; selecting the figure opens the exact single-page vector PDF for zooming.
